Front-End JavaScript: Make Your Web Pages Come Alive

A hands-on follow-up to HTML & CSS. Over five days you learn JavaScript from zero, take control of the page with the DOM, add forms, timers, storage and live data, and finish by building a complete interactive app.

Course Details

Prerequisites

  • HTML & CSS — completed Build & Publish Your First Website or equivalent
  • Comfortable writing HTML tags, CSS selectors, and page layouts
  • A laptop (Windows, macOS, or Linux) and charger
  • VS Code with the Live Server extension installed
  • A modern web browser with DevTools (Chrome, Edge, or Firefox)

What's Provided

  • Setup check of DevTools, the console, and a practice folder
  • The full 22-lesson course workbook (yours to keep)
  • Starter files and reference solutions for every lab
  • Instructor-led labs daily and a guided capstone build
  • A working interactive app of your own by the end of Day 5

What You'll Be Able to Do

Graduates leave able to add real interactivity to a web page unaided.

Write clean JavaScript with variables, types & operators
Control flow with conditionals, loops & functions
Model data with arrays, objects & array methods
Select, change, create & remove page elements
Respond to clicks, keys & form submissions
Validate forms with clear, accessible feedback
Save data with localStorage and fetch it from APIs
Debug with DevTools and structure a complete app
