Welcome to JavaScript

HTML is the skeleton. CSS is the paint. JavaScript is the wiring.

Three layers, one page

Structure · presentation · behavior

  • HTML — what is on the page
  • CSS — how it looks
  • JavaScript — what happens when users interact
  • Built into every browser — nothing to install
  • Event-driven: load, wait, react
  • JavaScript ≠ Java · ECMAScript = the rulebook

L02

Linking Scripts & the Console

Move the code into a file the page loads every time.

External script = the professional default

Link app.js before </body>

<body>
  <h1>JavaScript Practice</h1>
  <script src="app.js"></script>
</body>

<!-- or, in the head -->
<script src="app.js" defer></script>
  • Before </body>: every element exists
  • defer: download now, run after parsing
  • Head without defer: runs too early
WATCH Code between the tags of a src script is silently ignored.
Your #1 debugging tool

The console methods

console.log("Regular log message");
console.warn("This is a warning");
console.error("This is an error (not a real one!)");
console.log("5 + 3 =", 5 + 3);
console.table(["HTML", "CSS", "JavaScript"]);
// comment the WHY, not the what
  • Output goes to the Console, not the page
  • Nothing shows? Check the file name & folder
  • Real errors say Uncaught + file:line
L03

Variables & Data Types

A variable is a labeled box. A type says what's inside.

const by default · let when it changes

Declare, then use

const firstName = "Ray";
let age = 30;
let nickname = null;

age = 31;               // ✅ let can change
firstName = "Raymond";  // ❌ TypeError
console.log(`Hello, ${firstName}!`);
  • = means store, not "equals"
  • Never var in new code
  • Backticks + ${…} = template literal
WATCH const locks the variable, not an array's contents — push still works (Module 3).
string · number · boolean · null · undefined

typeof and its surprises

typeof "Hello"   // "string"
typeof 42        // "number"
typeof null      // "object" (!)
"5" + 3           // "53"
"5" - 3           // 2
149.99 - 29.99    // 120.00000000000001
  • null = deliberately empty
  • undefined = not assigned yet
  • Money: .toFixed(2)
WATCH Declaring the same name twice in one file is a SyntaxError — nothing in the file runs.
L04

Operators & Expressions

Calculate, compare, combine.

Always === and !==

Strict vs loose equality

5 === "5"     // false — type differs
5 == "5"      // true  — converts first
"" == 0       // true  (!)
"" == "0"     // false (!!)
10 % 3        // 1 — remainder
true && false || true  // true
  • % is remainder, not percent
  • && before ||; * before +
  • Falsy: false 0 "" null undefined NaN
WATCH "0" is truthy — it's a non-empty string.
