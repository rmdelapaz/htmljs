L13

Introduction to the DOM

HTML is the blueprint. The DOM is the building. JavaScript is the contractor.

Parents, children, siblings

Walk the tree

const list = document.querySelector("ul");
list.children;          // <li> elements
list.firstElementChild; // first <li>
list.firstChild;        // #text (whitespace!)
list.parentElement;     // one level up
  • document is the entry point
  • Use the Element properties
  • Elements panel = live DOM; View Source = the file
WATCH firstChild is usually the whitespace text node, not the first tag.
L14

Selecting & Modifying

If you know CSS selectors, you already know how to find elements.

Grab it, then change it

Text, classes, styles, data

const card = document.querySelector("#card");
card.querySelector("h2").textContent = "Ray";
card.classList.toggle("dark");
card.dataset.userId;   // "101"
getComputedStyle(card).color;
  • No match → null
  • querySelectorAll = static NodeList
  • Prefer classes over inline styles
WATCH element.style reads only inline styles — stylesheet values come back "".
textContent vs innerHTML

Never put user text in innerHTML

const input = '<img src="x" onerror="alert(1)">';

box.innerHTML = input;    // ❌ code runs
box.textContent = input;  // ✅ plain text
  • User input = forms, URLs, APIs, storage
  • innerHTML += rebuilds everything
  • …and wipes the listeners inside
WATCH A <script> via innerHTML won't run — onerror will. Not running ≠ safe.
L15

Events & Event Listeners

The event rings the doorbell. Your listener decides what happens.

Listen, then respond

addEventListener + the event object

form.addEventListener("submit", (event) => {
  event.preventDefault();  // no reload
  console.log(event.target);
});

btn.addEventListener("click", handleClick);
  • Pass the function — no ()
  • target = what was clicked
  • Events bubble up to ancestors
WATCH removeEventListener needs the same function reference — anonymous functions can't be removed.
One listener, every child

Event delegation

taskList.addEventListener("click", (event) => {
  const item = event.target.closest(".task-item");
  if (!item) return;
  if (event.target.closest(".delete-btn")) {
    item.remove();
  }
});
  • Works for tasks added later
  • closest() beats matches()
  • Capture ↓ · target · bubble ↑
WATCH focus, blur, mouseenter, mouseleave don't bubble — you can't delegate them.
L16

Creating & Removing

Create → configure → insert. Remove when you're done.

Build it in memory, then insert

createElement + textContent + append

const note = document.createElement("div");
note.classList.add("notification", type);
note.textContent = message;
area.prepend(note);
setTimeout(() => note.remove(), 5000);
  • append/prepend = children
  • before/after = siblings
  • replaceChildren() empties a container
WATCH Appending an element that's already on the page moves it. Clone for a copy.
Many elements, one insert

DocumentFragment

const fragment = document.createDocumentFragment();
for (const text of items) {
  const li = document.createElement("li");
  li.textContent = text;
  fragment.append(li);   // off-screen
}
list.append(fragment);   // one insertion
  • The fragment itself disappears
  • It's empty afterward
  • cloneNode(true) = deep copy
