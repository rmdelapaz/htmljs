Next Steps & Best Practices

Pros still write bugs. They just find them faster.

Read the error message

What · where · why

// Uncaught TypeError: Cannot read
//   properties of null (reading 'textContent')
//   at renderUser (app.js:45:23)

// WHAT:  .textContent on null
// WHERE: app.js line 45, renderUser
// WHY:   querySelector found nothing
  • null → check the selector
  • not a function / not defined → spelling, scope
  • Unexpected token → the line before
  • undefined → log the data's shape
Debug with a loop, not with luck

Hypothesis → test → fix

console.table(notes);
console.time("fetch");
await fetch("/api/data");
console.timeEnd("fetch");

function processOrder(order) {
  const total = calculateTotal(order.items);
  debugger;  // pauses here
}
  • Read → reproduce → hypothesis → test → fix → verify
  • Breakpoints: click a line number in Sources
  • Stuck? Explain it to a rubber duck
WATCH debugger is ignored unless DevTools is open — open it, then reload.
