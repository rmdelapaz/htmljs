L17

Forms & Validation

Catch mistakes before anything is sent.

Stop the reload, then check

submit + preventDefault()

form.addEventListener("submit", e => {
  e.preventDefault();  // line one
  const email =
    form.elements.email.value.trim();
  if (!isValidEmail(email)) {
    showError(form.elements.email,
      "Please enter a valid email");
  }
});
  • .value is always a string
  • Validate on blur, re-check on input once touched
  • Errors = text + color, role="alert"
WATCH Client-side checks can be bypassed. The server always validates again.
L18

Timers & Animation

Run code later, run it again, run it smoothly.

Save the ID, so you can stop it

setTimeout · setInterval · rAF

let intervalId = null;
function start() {
  if (intervalId) return; // no doubles
  intervalId = setInterval(tick, 1000);
}
function pause() {
  clearInterval(intervalId);
  intervalId = null;
}
  • Pass tick, don't call tick()
  • Debounce waits for a pause · throttle limits the rate
  • Motion: toggle a class and let CSS animate
WATCH Clicking Start twice without a guard creates two intervals, so the timer runs at double speed.

L19

Local Storage

Make your page remember, even after a refresh.

Strings in, strings out

The JSON round trip

function loadTodos() {
  try {
    const s =
      localStorage.getItem("todos");
    return s ? JSON.parse(s) : [];
  } catch { return []; }
}
function saveTodos(todos) {
  const s = JSON.stringify(todos);
  localStorage.setItem("todos", s);
}
  • Missing key returns null
  • Load → render → change → save → render
  • sessionStorage: same API, one tab
WATCH dataset.id is a string. Use Number() before comparing it to todo.id. And never store tokens.
L20

APIs & Fetch

Ask a server for live data and handle every answer.

async / await + response.ok

Every outcome, handled

async function searchUser(name) {
  showLoading();
  try {
    const res = await fetch(url);
    if (res.status === 404)
      return showError("Not found");
    if (!res.ok) return showError(…);
    showUser(await res.json());
  } catch {
    showError("Network error");
  }
}
  • fetch() returns a Promise of a Response
  • Three UI states: loading · data · error
  • API text goes in with textContent
WATCH A 404 doesn't reach catch. Only network failures reject.
