L09

Arrays

One variable, an ordered list of values. Counting starts at 0.

Add, remove, search

The everyday array toolkit

const todos = ["Shop", "Walk dog"];
todos.push("Read");      // add to end
todos.shift();           // remove first
todos[0];                // "Walk dog"
todos.at(-1);            // "Read"
todos.includes("Read"); // true
todos.indexOf("Nap");   // -1
  • push/pop = end · unshift/shift = start
  • indexOf → -1 when not found
  • for...of is the default loop
Same name, opposite effect

splice vs slice

const l = ["a","b","c","d","e"];
l.slice(1, 3);   // ["b","c"] l unchanged
l.splice(1, 2);  // ["b","c"] l = ["a","d","e"]

l.splice(1, 0, "x"); // insert
l.splice(1, 1, "y"); // replace
  • slice copies — original untouched
  • splice edits the original
  • [...arr] = a quick copy
WATCH "My array lost items" → a splice where they meant slice.
L10

Objects

Arrays store by position. Objects store by name.

Properties & methods

Dot, bracket & this

const player = {
  name: "Ray",
  score: 0,
  addPoints(n) { this.score += n; }
};
player.addPoints(10);
const key = "score";
player[key];   // 10
  • Dot by default; bracket for keys in variables
  • this = the object before the dot
  • Object.entries to loop key + value
WATCH Arrow functions have no own this — write methods as name() { }.
Compared by reference

Same contents ≠ same object

const a = { x: 1 };
const b = { x: 1 };
const c = a;
a === b;   // false — two objects
a === c;   // true — one object
c.x = 99;  // a.x is 99 too!
  • === asks "same object?"
  • Compare a property: c.name === "Bob"
  • { ...a } makes a real (shallow) copy
L11

Array Methods

Describe what to do to each item — the method does the looping.

Three shapes of output

map · filter · reduce

const n = [10, 20, 30, 40];
n.map(x => x * 2);      // [20,40,60,80]
n.filter(x => x > 15);  // [20,30,40]
n.reduce((s, x) => s + x, 0); // 100
n.every(x => x > 5);   // true
  • map → same length
  • filter → fewer items
  • reduce → one value (always pass the start)
WATCH Braces need return: x => { x * 2 } gives undefined.
Pipelines

filter → sort → map

products
  .filter(p => p.inStock)
  .sort((a, b) => a.price - b.price)
  .map(p => p.name);

[40, 100, 1].sort(); // [1, 100, 40] !
(374.94000000000005).toFixed(2); // "374.94"
  • Filter first, transform last
  • Numbers need (a, b) => a - b
  • toFixed(2) for display (it's a string)
WATCH sort() mutates the original — use toSorted() or sort a copy.
L12

Strings & Template Literals

Every string method returns a new string.

Search, slice, clean, format

The text toolkit

const s = "  Hello, World!  ".trim();
s.slice(-6);              // "World!"
s.endsWith("!");          // true
s.split(", ");            // ["Hello", "World!"]
"7".padStart(3, "0");    // "007"
`Hi, ${name}!`           // backticks only
  • Store the result: s = s.trim()
  • split → map → join for word-level edits
  • /\s+/g = "one or more spaces" (read, don't memorize)
WATCH name.trim(); alone does nothing — strings are immutable.
