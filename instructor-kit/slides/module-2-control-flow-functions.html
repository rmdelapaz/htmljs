L05

Conditionals

Run different code depending on what's true.

First true condition wins

if / else if / else

if (score >= 90) {
  letter = "A";
} else if (score >= 80) {
  letter = "B";
} else {
  letter = "F";
}
  • Check the highest range first
  • Always use braces, even for one line
  • Guard clauses: handle problems first
WATCH if (quantity) treats a valid 0 as missing — 0 is falsy.
One value, many options · or just two

switch & the ternary

switch (letter) {
  case "A":
    message = "Excellent work!";
    break;
  default:
    message = "Keep going";
}
const status =
  score >= 60 ? "Pass" : "Fail";
  • Forget break → it falls through
  • default is the switch's else
  • Ternary: short choices only, never nested
WATCH switch uses ===: "5" never matches case 5.
L06

Loops

Write it once. Let JavaScript repeat it.

Start · check · update

for and for...of

for (let i = 1; i <= 5; i++) {
  stars += i <= rating ? "★" : "☆";
}

for (const item of products) {
  const name = item.toLowerCase();
  if (name.includes(term)) count++;
}
  • for — known count
  • while — until a condition changes
  • for...of values · for...in object keys
  • break exits · continue skips
WATCH i <= arr.length runs one extra time → undefined.
L07

Functions

A recipe: define once, call it any time.

Three ways to write one

Declaration, expression, arrow

// declaration — hoisted
function capitalize(str) {
  return str[0].toUpperCase() +
    str.slice(1).toLowerCase();
}
// expression
const double = function(n) {
  return n * 2;
};
// arrow + default parameter
const pluralize =
  (n, one, many = one + "s") =>
    `${n} ${n === 1 ? one : many}`;
  • return hands a value back — none gives undefined
  • Defaults fill missing arguments
  • Return an object: n => ({ name: n })
WATCH A const function called before its line → ReferenceError, not TypeError.
L08

Scope & Hoisting

Can I use this variable here?

Blocks, the chain & the TDZ

Who can see what

if (true) {
  var leaked = "escaped";
  let kept = "stayed";
}
console.log(leaked); // "escaped"

console.log(nickname); // undefined
var nickname = "Ray";
// ReferenceError (TDZ):
console.log(age);
let age = 25;
  • let/const: block · var: function
  • Lookups go outward, never inward
  • Use let/const; skip var
WATCH Don't demo with var name — it collides with window.name.
A function with a memory

Closures

function createScoreTracker() {
  let score = 0;
  return {
    addPoints(p) { score += p; },
    penalty(p) {
      score -= p;
      if (score < 0) score = 0;
    },
    getScore() { return score; },
    reset() { score = 0; }
  };
}
  • score survives after the function returns
  • Only the returned methods can touch it
  • Each call makes a new, separate tracker
