L13

Introduction to the DOM

45 min
By the end you can
  • Explain what the DOM is and how the browser builds it from HTML
  • Name the key objects: window, document, elements and nodes
  • Move around the tree with parent, child and sibling properties
  • Tell the live DOM (Elements panel) from the HTML source (View Source)
Key ideas — blueprint, building, contractor
  • HTML is the blueprint, the DOM is the building, JavaScript is the contractor who remodels it after it's built.
  • document is your entry point to the page. window is the browser window that holds everything.
  • Elements are node type 1; text is type 3. The line breaks between your tags are text nodes too.
  • Use the Element properties: parentElement, children, firstElementChild, nextElementSibling. They skip the whitespace.
  • Console changes live in memory. Refresh and they're gone; View Source never shows them.
Worked example
const list = document.querySelector("ul");
list.children.length;       // how many <li> elements
list.firstElementChild;     // the first <li>
list.firstChild;            // #text — the whitespace before it!
list.firstElementChild.nextElementSibling;  // the second <li>
list.parentElement;         // whatever contains the list

L14

Selecting & Modifying Elements

50 min
By the end you can
  • Select elements with querySelector, querySelectorAll and getElementById
  • Change text safely with textContent
  • Add, remove and toggle classes with classList; set inline styles
  • Read and set attributes and data-* values
Key ideas
  • If you know CSS selectors, you know querySelector. No match returns null.
  • querySelectorAll returns a NodeList: forEach yes, map no — spread it with [...list]. It's a snapshot; re-query after adding elements.
  • textContent for anything a user typed. innerHTML parses HTML, so user text in it can run an attacker's code (XSS).
  • Prefer classes over inline styles. element.style only reads inline styles; use getComputedStyle to read what's actually applied.
  • data-item-id in HTML is dataset.itemId in JavaScript, and its value is always a string.
Worked example
const card = document.querySelector("#card");
card.querySelector("h2").textContent = "Ray de la Paz";
card.classList.add("highlight");
card.classList.toggle("dark");
console.log(card.dataset.userId);   // "101"
card.dataset.status = "active";       // adds data-status="active"
document.querySelector("#website").href = "https://example.com";

L15

Events & Event Listeners

55 min
By the end you can
  • Respond to clicks, typing, key presses and form submits with addEventListener
  • Use the event object (target, key) and preventDefault()
  • Explain bubbling and capturing
  • Handle many children with one delegated listener; remove listeners
Key ideas — the doorbell
  • The event is someone pressing the doorbell; the listener is what you decide to do when it rings.
  • Pass the function, don't call it: addEventListener("click", handleClick) — no ().
  • event.target = what was actually clicked. event.currentTarget = where the listener lives.
  • event.preventDefault() stops the browser's own behavior, like a form reloading the page.
  • Events bubble up from the target to its ancestors. Delegation uses this: one listener on the parent + event.target.closest(".btn").
  • focus, blur, mouseenter and mouseleave don't bubble, so you can't delegate them.
Worked example
form.addEventListener("submit", (event) => {
  event.preventDefault();                   // no page reload
  const text = taskInput.value.trim();
  if (!text) return;
  // ...build the <li>, put text in with textContent
});

taskList.addEventListener("click", (event) => {  // ONE listener
  const item = event.target.closest(".task-item");
  if (!item) return;
  if (event.target.closest(".delete-btn")) item.remove();
});

L16

Creating & Removing Elements

50 min
By the end you can
  • Create an element, configure it, and insert it into the page
  • Insert with append/prepend (children) and before/after (siblings)
  • Remove, replace, clear and clone elements
  • Batch many inserts with a DocumentFragment
Key ideas — create, configure, insert
  • document.createElement("div") makes an element in memory. It isn't on the page until you insert it.
  • An element lives in one place. Appending an existing element moves it; use cloneNode(true) for a copy.
  • el.remove() deletes; el.replaceWith(other) swaps; parent.replaceChildren() empties.
  • User text → createElement + textContent. Keep innerHTML for fixed markup you wrote yourself. innerHTML += rebuilds everything and wipes listeners.
  • A DocumentFragment collects elements off-screen; appending it inserts them all in one step and leaves it empty.
Worked example
function showNotification(type, message) {
  const note = document.createElement("div");
  note.classList.add("notification", type);

  const text = document.createElement("span");
  text.textContent = message;              // safe

  const close = document.createElement("button");
  close.textContent = "×";
  close.setAttribute("aria-label", "Dismiss notification");

  note.append(text, close);
  area.prepend(note);                      // now it's visible
  setTimeout(() => note.remove(), 5000);
}
