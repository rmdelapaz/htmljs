L09

Arrays

50 min
By the end you can
  • Create an array and read or change any element by index (starting at 0)
  • Add and remove with push, pop, unshift, shift
  • Insert, remove, or replace anywhere with splice
  • Search with includes, indexOf, find; copy with slice and spread
  • Loop with for, for...of, and forEach
Key ideas
  • The first element is arr[0]; the last is arr[arr.length - 1] or arr.at(-1). Out of range gives undefined, not an error.
  • push/pop work on the end; unshift/shift on the start. push returns the new length; pop and shift return the removed item.
  • indexOf returns -1 when the value isn't there. Check for it before you splice.
  • splice changes the original; slice makes a copy. Same-sounding names, opposite effects.
  • A const array can still change its contents. const only stops you reassigning the variable.
Worked example
const colors = ["red", "yellow", "purple"];
colors.splice(1, 0, "orange");   // insert: ["red", "orange", "yellow", "purple"]
colors.push("blue");              // add to end
const i = colors.indexOf("yellow"); // 2
if (i !== -1) colors.splice(i, 1);  // remove it safely

for (const color of colors) {
  console.log(color);               // red, orange, purple, blue
}

L10

Objects

50 min
By the end you can
  • Create objects and read, add, update, and delete properties
  • Choose dot notation (default) or bracket notation (odd keys, keys in variables)
  • Write methods that use this
  • Work with nested data and arrays of objects; destructure properties
  • Loop over Object.keys, values, and entries
Key ideas
  • An object stores key: value pairs, so you look data up by name instead of position.
  • obj[field] uses the value of field; obj.field looks for a key literally named "field".
  • Inside a method, this is the object before the dot. Arrow functions don't have their own this, so write methods as greet() { … }.
  • An array of objects is like a spreadsheet: each object is a row, each key a column.
  • Objects are compared by reference: two objects with the same contents are still not ===.
Worked example
const player = {
  name: "Ray",
  score: 0,
  addPoints(points) {          // method: regular syntax, not an arrow
    this.score += points;
    return `${this.name}: ${this.score} points`;
  }
};
player.addPoints(10);          // "Ray: 10 points"

const { name, score } = player; // destructuring
for (const [key, value] of Object.entries({ name, score })) {
  console.log(`${key} → ${value}`);  // name → Ray, score → 10
}

L11

Array Methods

55 min
By the end you can
  • Transform with map, keep matches with filter, collapse with reduce
  • Ask yes/no questions with some and every; get the first match with find
  • Sort numbers and objects with a compare function
  • Chain methods into a filter → sort → map pipeline
Key ideas
  • map → new array, same length · filter → new array, fewer items · reduce → one value. forEach returns undefined; use it for side effects only.
  • Always give reduce an initial value: reduce((sum, n) => sum + n, 0).
  • Plain sort() sorts as text: [40, 100, 1, 5, 25] → [1, 100, 25, 40, 5]. For numbers use (a, b) => a - b.
  • sort and reverse change the original; toSorted or [...arr].sort() don't.
  • Money math gives long decimals like 374.94000000000005. Display with toFixed(2), which returns a string.
Worked example
const result = products
  .filter(p => p.category === "electronics")  // keep electronics
  .sort((a, b) => a.price - b.price)             // cheapest first
  .map(p => `${p.name}: $${p.price}`);         // format
// ["Tablet: $449", "Phone: $699", "Laptop: $999"]

const total = products
  .filter(p => p.category === "electronics")
  .reduce((sum, p) => sum + p.price, 0);     // 2147

L12

Strings & Template Literals

40 min
By the end you can
  • Build text with template literals: `Hi, ${name}!` and multiline strings
  • Search with includes, startsWith, endsWith, indexOf
  • Extract with slice and at; clean with trim, toLowerCase, replace
  • Split text into arrays and join arrays back into text
  • Format with padStart, padEnd, and repeat
Key ideas
  • Strings are immutable. Every method returns a new string, so store the result: name = name.trim();
  • Only backticks interpolate ${…}. Regular quotes print it literally.
  • slice works like array slice, and negatives count from the end: "Hello, World!".slice(-6) → "World!".
  • replace changes the first match; replaceAll changes every match.
  • split → map → join transforms text word by word.
  • You'll read a few regular expressions in the lab: /\s+/g = "one or more spaces, everywhere".
Worked example
function titleCase(str) {
  return str
    .split(" ")
    .map(word => word[0].toUpperCase() + word.slice(1).toLowerCase())
    .join(" ");
}
titleCase("the QUICK brown FOX");   // "The Quick Brown Fox"

"42".padStart(6, "0");             // "000042"
"report-2026.pdf".endsWith(".pdf"); // true
