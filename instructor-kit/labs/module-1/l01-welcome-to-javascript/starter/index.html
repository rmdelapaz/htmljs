This page has no JavaScript in it at all — just HTML and CSS. It's a safe place to practice typing JavaScript into the Console.

Open the Console

  • Any browser: press F12, then click the Console tab
  • Chrome / Edge on Windows or Linux: Ctrl + Shift + J
  • Chrome / Edge on Mac: Cmd + Option + J

Try these, one at a time

  1. document.title
  2. document.title = "I changed this with JavaScript!"
  3. document.body.style.backgroundColor = "lightyellow"

Refresh the page and everything goes back to normal — you only changed your copy.
