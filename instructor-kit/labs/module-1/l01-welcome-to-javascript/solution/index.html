Reference solution for the L01 worksheet. app.js runs the same three statements students type into the Console — open DevTools (F12) to compare.

What the worksheet statements do

  1. document.title — reads the tab text (a string)
  2. document.title = "…" — changes the tab text, for your copy only
  3. document.body.style.backgroundColor = "lightyellow" — repaints the page
