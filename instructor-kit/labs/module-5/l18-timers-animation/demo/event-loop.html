Event loop: who runs first?

Ask the room to predict the order before you click. Then click and read the output left to right. The same lines are logged to the console.

console.log("A");
setTimeout(() => console.log("B"), 0);         // task queue
Promise.resolve().then(() => console.log("C")); // microtask queue
console.log("D");

    Border colors: blue = synchronous · purple = microtask (promise) · amber = task (timer)
